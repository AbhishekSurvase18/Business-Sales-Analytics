# Business Sales Analytics & Excel Automation

A Python-based business sales analytics project that reads sales data from CSV and automatically generates a professional Excel report.

## Features

- Read sales data from CSV
- Calculate total sales
- Calculate average sale
- Identify highest sale
- Analyze category-wise sales
- Generate automated Excel report
- Create sales chart
- Format Excel worksheets

## Technologies

- Python
- Pandas
- XlsxWriter
- Microsoft Excel

## Project Structure

Business-Sales-Analytics/
├── sales.csv
├── sales_report.py
├── requirements.txt
├── README.md
└── Business_Sales_Report.xlsx

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the project:

python sales_report.py

## Output

The project generates:

Business_Sales_Report.xlsx

The Excel report contains:

- Sales Data
- Summary
- Category Sales
- Category-wise Sales Chart

## Use Case

This project can help small businesses automate basic sales reporting and reduce manual Excel work.
